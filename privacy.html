Privacy Policy

Last updated: 5 November 2026

Who we are

TimeLoop is a community that runs Teeworlds/DDNet map events. This website and the "TimeLoop Studio" publishing tool are run by the TimeLoop event organizers.

This website

The website is a static page hosted on GitHub Pages. It shows event results, in-game player names, run times and map files. It has no accounts, no cookies of its own and no tracking. GitHub may log visits as described in GitHub's own privacy statement. Player skins are loaded from the DDNet skin database.

TimeLoop Studio and TikTok

TimeLoop Studio is a private desktop tool used only by the TimeLoop organizers to upload TimeLoop event videos to the TimeLoop TikTok account. When the organizer connects their TikTok account, the tool receives an access token and the account's basic profile (display name and open ID). That token is stored only on the organizer's own computer and is used only to upload videos to that account's drafts. We do not collect, sell or share data from any other TikTok users.

Removing data

The organizer can disconnect the tool at any time in TikTok's settings (Security → Manage app permissions). If you want your in-game name removed from the results, ask us in our Discord server.
